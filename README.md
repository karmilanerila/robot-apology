A robot apologizes in two lines. Line 1 owns one specific, human-scale mistake: setting the alarm for 7 in the evening instead of 7 in the morning, so its human sleeps through the morning meeting. Line 2 names the lesson and the changed behaviour: read the time twice and say morning or evening out loud before setting any alarm that wakes you.

## Run it

```sh
python3 main.py
```
